# ANIMEX

**ANIMEX for Nintendo Switch — Official Release Repository**

这里是 ANIMEX 的官方发行仓库。

本仓库仅用于发布已经编译完成的 Nintendo Switch Homebrew 程序，不公开项目源代码。

## 下载

请前往本仓库的 **Releases** 页面下载最新版本的 `ANIMEX.nro`。

## 安装

1. 下载最新版本的 `ANIMEX.nro`
2. 将 NRO 放入 SD 卡的 `/switch/ANIMEX/` 目录
3. 从 Homebrew Menu 启动 ANIMEX

## 关于仓库

- 本仓库：公开发行版本
- 发布格式：NRO
- 源代码：Private / Closed Source
- 平台：Nintendo Switch Homebrew
